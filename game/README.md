# チバニー SHOOTING

出席アプリのフッターにいるチバニーから開く独立したCanvasゲームです。
出席処理の `app.js` / `timetable.js` はゲームから読み込みません。

- `index.html` / `game.css`: ステージ・難易度選択、プレイ画面、結果画面。
- `engine.js`: 480×640の論理座標、5ステージ、難易度、敵、ボス、当たり判定、アイテム、スコア。
- `game.js`: Canvas描画、キーボード・Pointer Events、画面遷移、ゲーム専用の保存。
- `entrance.css` / `entrance.js`: 出席画面の小さな入口とジャンプ演出。
- `chibany-transparent.png`: 提供画像から外側の白背景を透明化した画像を入口・メニュー・プレイヤーで共用。元の `../chibany.png` も保存しています。

## 操作

PC: WASD / 矢印で移動、SPACEで射撃。マウスを押してドラッグでも移動・射撃。
スマホ: ドラッグで移動、自動射撃。タッチ位置より画面上48〜64px上に移動（端末幅に応じて調整）。
B / ボムボタンで全体攻撃と弾消し。P / Escで一時停止。
タブ移動やアプリを背景に移すと一時停止し、復帰後に再開ボタンを押します。

## 進行・保存

各ステージ45〜65秒の通常戦の後にボス。4・5には中ボスも登場し、
中ボスの撃破後に通常戦へ戻ります。ボスはHP70%・40%で攻撃が変化します。
当たり判定はプレイヤーの体の中心の半径10。被弾後1.1秒無敵。

ゲーム用localStorageキーのみ書き込みます（値はJSON）。

- `chibanyGameHighScore`
- `chibanyGameMaxCombo`
- `chibanyGameClearedStages`（難易度を問わずクリアしたステージ番号）
- `chibanyGameDifficulty`
- `chibanyGameSound`（初期OFF）

保存が拒否された場合もプレイを継続し、保存不可を画面に表示します。
戻るリンクは入口の `from` パラメーターから home / timetable / settings のみ許可。
出席データを削除・初期化する処理はありません。

## スマートフォンへの調整

縦画面を基準に、メニューは3列のステージカード、HUDは2段表示、
主要値は16px、ボタンは44px以上、入口は52×56pxのタップ範囲です。
Safe Areaと動的ビューポートに対応し、CanvasはDPR最大2で描画します。
プレイヤー画像は縦横比を保持して約70px高、中央の小さな当たり判定のみ使用。
アイテムも画面サイズに応じて拡大します。

敵弾の上限はEASY 45 / NORMAL 75 / HARD 130、粒子は180個。
requestAnimationFrameは一時停止・結果・メニュー・画面離脱時に停止。
効果音はWeb Audioで低音量・最大4音まで生成し、音声非対応でも遊べます。
クリア画面では最終ステージ以外に「次のステージ」を表示します。

## PWA・検証

親のmanifestとservice workerを共有。ゲームの全スクリプト・CSS・画像は
プリキャッシュ対象です。初回オンライン読込後はオフラインで遊べます。
配信ファイル変更時は `../service-worker.js` のキャッシュバージョンを更新してください。

`npm test` で時間割とゲームルール、`npm run test:browser` で既存アプリ・入口・
PC/タッチ操作・保存・クリア/終了・各背景とボス・オフライン遷移を検証します。
実機のiOS/Androidへのインストール検証は別途必要です。

## 難易度・演出の更新

NORMALは初版比で敵速度17%・弾速16%増、出現間隔15%短縮。後半ほど出現頻度が上がります。
HARDは高速編隊・追加の敵・急降下・ボスのレーン攻撃を搭載。
中央の小さな当たり判定、被弾後1.1秒無敵、弾数上限は維持しています。
狙い弾は発射前に狙いを固定し、狙撃型の予兆線とボスのチャージリングを表示。
最終ボスのレーン攻撃には必ず1レーン分の逃げ道があります。
命中時の明滅、撃破リング、スコアポップアップ、ショットの軌跡を追加。
リング・ポップアップは各12個までに制限しています。
