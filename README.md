# 千葉工業大学 出席管理（2026年度後期）

紅葉と夕方の空をイメージしたAutumn Campusデザインの静的Webアプリです。ビルドやサーバー側の設定は不要です。

## 利用方法

- 上部に現在の授業と次の授業を表示します。授業がない時間は次の授業を表示し、土日・月曜は翌登校日まで検索します。
- 出席受付は日本時間の**開始30分前から開始1時間後ちょうどまで**です。それを過ぎると無効になります。
- 授業カードでは受付時間を確認します。「教室番号で出席」は時間割・曜日・選択授業・時刻に関係なく、3〜10桁の教室番号から出席ページを開けます。全角数字は半角に変換します。教室の存在や実際の受付状況は、開いた大学のページで確認してください。
- 「選択授業の設定」で金曜7〜8限の科学哲学または映画における恐怖の歴史のカードを選びます。初期状態は未設定で、片方だけが時間割・現在／次の授業・出席URL・通知に反映されます。「選択内容を保存しました」は4秒間表示し、その後もチェックマークと枠線で選択状態を表示します。
- 選択はlocalStorageの`cit-attendance-2026-fall-friday-elective`に`A`または`B`として保存します。同一ブラウザ・同一オリジンで再読み込み後も維持され、他のタブにも反映されます。保存できない環境では画面に案内を表示します。
- 通知は従来どおりページを開いている間に確認し、受付開始30分前と開始5分前に通知します。通知許可が必要です。モバイルの通知はアプリを開き、授業カードから出席できます。
- 通常の週間時間割です。祝日・休講・学期の開始終了日は自動判定しません。大学の学年暦と照合してください。
- オフラインでは保存した時間割を参照できます。大学の出席ページを利用するには通信が必要です。

## データとURLの変更箇所

時間割は`timetable.js`の`timetable`と`electives`、時限は`PERIODS`に定義しています。各授業は表示用の`room`と半角数字のみの`roomCode`を別々に持ちます。

出席URLは同ファイルの`getAttendanceUrl()`で検証し、`ATTENDANCE_BASE_URL + encodeURIComponent(classData.roomCode)`で生成します。

```text
https://attendance.is.chibatech.ac.jp/attendance/class_room/1232
```

選択の保存と再描画は`index.html`の`readElective()`、`writeStorage()`、`fridayElective`の`change`イベントで処理します。選択変更時には現在表示中のカードと通知対象も更新します。

## ローカル確認

```sh
python3 -m http.server 8000
```

ブラウザで`http://localhost:8000/`を開きます。PWAにはHTTPSまたはlocalhostが必要です。

テストにはNode.js 20以上とPython 3を使います。

```sh
npm ci
npx playwright install chromium --only-shell
npm test
npm run test:browser
```

ブラウザテストは親ディレクトリを公開し、`/attendance-system/`というGitHub Pages相当のサブパスで検証します。チェックアウト名が異なる場合は`playwright.config.js`のパスを合わせてください。大学サイトへのアクセスはテストで差し替え、実際の出席登録は行いません。

既存のChromiumを使う場合は、環境変数`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`に実行ファイルの絶対パスを指定できます。

2026年9月20日の確認結果：ロジックテスト6件、Chromiumでのブラウザテスト12件がすべて成功しました。受付の境界、全授業データ・URL、選択の保存と別タブへの反映、通知、320〜1440pxの表示、オフライン再読み込みを確認し、ブラウザのJavaScript・コンソールエラーはありませんでした。スマートフォンはブラウザの画面幅で検証しており、実機でのPWAインストールや大学側の出席登録は実施していません。

秋のUIはPC・スマートフォンのスクリーンショットで確認済みです。ヘッダーには生成した紅葉と夕日のキャンパスイラストを同梱し、文字の背景に暗いグラデーションを重ねています。スマートフォンでは画像位置を調整し、画面幅と画素密度に応じて768px / 1536pxのWebPを読み込みます。1536×1024pxのPNG原本は保存用で、画面では読み込みません。生成方法とプロンプトは`assets/README.md`を参照してください。装飾は静止表示で操作を妨げません。動きを減らす設定ではホバーの移動も即時に切り替わります。

## GitHub Pagesへの反映

1. 変更・追加ファイルをコミットし、既存のGitHub Pages公開対象ブランチへpushしてください。通常の運用が`main`なら`main`が対象です。
2. 未設定の場合はリポジトリのPages設定で公開元ブランチとルートディレクトリを指定します。既存のデプロイ方法がある場合はそれに従ってください。
3. 配信完了後、公開ページをオンラインで再読み込みしてください。出席先ドメインと金曜の選択設定を確認します。

公開先は https://komikomi703.github.io/attendance-system/ です。外部サービスのAPIキーなどの追加設定は不要です。初回利用時は金曜の選択授業を選んでください。

Service workerのキャッシュ名は`cit-attendance-2026-fall-v12`です。秋テーマの`styles.css`と表示用WebPの両サイズもオフライン用に保存します。今後配信ファイルを変更する際は`CACHE_NAME`も更新してください。オンラインでは最新ファイルを取得し、通信できないときにキャッシュを使います。
